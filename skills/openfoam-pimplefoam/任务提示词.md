# OpenFOAM pimpleFoam 任务提示词

发给 Agent 时可直接复制下面任一段作为用户消息，触发并正确执行 openfoam-pimplefoam 技能。

---

## 简短版（指定目录）

```
请使用 openfoam-pimplefoam 技能，在指定目录 /home/notrickno/桌面/openfoam 下完成：用 pimpleFoam 做偏心圆柱的层流不可压模拟。参数：运动粘度 0.006 m²/s，入口速度 4 m/s，初始速度 0 m/s；时间 0 到 2 s，时间步 0.005 s，每 0.1 s 输出一次。请先阅读该技能全文，按技能要求用 write 工具创建或补全算例文件，在算例目录下运行 ./Allrun；若报错先诊断再修，不要一上来就重建全部文件。
```

---

## 完整版（含技能约束）

```
在指定目录 /home/notrickno/桌面/openfoam 下完成以下 OpenFOAM 任务：

任务：用 pimpleFoam 做偏心圆柱（offset cylinder）的层流不可压流动模拟。
参数：运动粘度 ν = 0.006 m²/s，入口速度 4 m/s，初始速度 0 m/s；模拟时间 0～2 s，初始时间步 0.005 s，每 0.1 s 输出结果。

请务必使用 openfoam-pimplefoam 技能并严格按技能执行：
1. 先阅读技能全文（尤其是「Agent: read this first」和「Create case from scratch」）。
2. 若目录下没有完整算例：用 write 工具按技能中的 Template 1～11 逐个创建 11 个文件，不要用 echo 或 shell 写多行文件。
3. 运行前确认 11 个文件齐全，在算例目录下执行：cd /home/notrickno/桌面/openfoam && ./Allrun。
4. 若出现「controlDict」或其它报错：先诊断（列出目录、检查已有文件内容），只修复缺失或错误项，不要默认重建全部 11 个文件。
```

Read the skill first; create or fix the case with the write tool (full Template 1–11 content), then run from the case dir: cd /home/notrickno/桌面/openfoam && ./Allrun. On errors, diagnose before fixing; do not blindly recreate all 11 files.
